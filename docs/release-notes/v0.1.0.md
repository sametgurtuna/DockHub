### What's New in v0.1.0

The initial release of DockHub — a modern, customizable floating dock for Windows designed as an elegant alternative to the traditional taskbar.

---

#### Key Features
- **Floating Glass Dock:** Smooth glass backdrop with customizable accent tint, corner radius, and blur effects.
- **Application Management:** Pin favorite applications, switch between running windows, and access quick actions.
- **Modular Widgets:** Built-in modular widgets including digital clock, system resources, and media controls.
- **Custom Positioning:** Place the dock on any screen edge (bottom, top, left, right) with automatic screen work-area adaptation.
- **Non-Admin Installation:** Self-contained installer running entirely in user space without requiring administrator privileges.

---

### Download & Installation
- Download and run `DockHub-Setup-0.1.0-x64.exe` below.
- **Requirements:** Windows 10 (1809+) or Windows 11 (64-bit).
