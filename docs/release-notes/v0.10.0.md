### ✨ What's New in v0.10.0

The first step toward 1.0: DockHub moves to .NET 10, and when it does crash, it comes back by itself and tells you what happened.

#### 🛟 Back After a Crash
- **Windows starts DockHub again after a crash or a hang.** In 0.9.1 the dock could vanish without a word, and you had to start it yourself. Now DockHub asks Windows to restart it. Windows does this only for a program that has been running for at least a minute, and never after an update or a restart of the PC.
- **No endless loop.** If Windows has to restart DockHub a third time within 10 minutes, DockHub stops instead, leaves the Windows taskbar visible and says so in a notification. Starting DockHub yourself still works. Turn the automatic restart back on in *Settings › Backup and troubleshooting*.
- **You'll know what happened.** When DockHub didn't shut down properly last time (a crash, or ending it in Task Manager), the next start shows a notification with *Report a problem* and *Open log*. A PC that restarted in the meantime (shutdown, power loss) is not reported.
- **Reports that say where, and nothing personal.** DockHub reads what Windows recorded about the crash: the module, the error code, the .NET exception type and the first lines of the stack trace. Exception messages, file paths and window titles are left out. *Report a problem* puts this into a new *Crash* field of the GitHub bug report, and *Settings › About › Last crash* shows it too.

#### ⚙️ .NET 10
- DockHub now runs on **.NET 10**, which Microsoft supports until November 2028. .NET 8, which 0.9 used, loses support on 10 November 2026. The installer carries the runtime, so there is nothing extra to install.
- Windows 10 1809 stays the minimum; nothing changes in what DockHub needs.

---

### 🛠️ Improvements & Fixes
- Reordering items by dragging in *Settings › Dock items* no longer depends on a serializer that .NET removed; drag data now only ever carries an item's id.
- Restoring the Windows taskbar no longer deletes `session.json`, so crash information survives it.
- The diagnostics report (*Settings › About › Copy diagnostics*) includes the last crash and whether the automatic restart is on.
- For testing: with `"debugLogging": true` in `config.json`, `DockHub.exe --crash-test` crashes DockHub on purpose after 65 seconds.
- New text in Turkish, German and Spanish.
- 30 new unit tests (400 in total).

### 📥 Download & Install
- **Installer:** Download `DockHub-Setup-0.10.0-x64.exe` from Assets below and run it. It upgrades your existing install in place and keeps your settings. If you have 0.9.x, you can also install it from **Settings > About**.
- **Requirements:** Windows 10 1809 or newer / Windows 11, x64.
