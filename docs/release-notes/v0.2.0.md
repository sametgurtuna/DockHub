### What's New in v0.2.0

Introducing the AI Usage widget, Windows Settings integration, and enhanced window management.

---

#### New Features
- **AI Usage Widget:** Real-time tracking of Claude Code subscription usage (monitoring 5-hour session windows and weekly limits) directly from the dock.
- **Windows Settings Shortcut:** Direct access to Windows Settings from the dock's context menu.
- **Instant Task Termination:** Added an "End Task" action on running application icons to force-terminate unresponsive processes without opening Task Manager.

---

#### Bug Fixes & Polish
- Fixed an issue where right-clicking a system tray icon would simultaneously open the dock's background context menu.
- Resolved submenu dismissal where moving the cursor toward submenus (such as dock position selection) would prematurely close the menu.

---

### Download & Installation
- Download and run `DockHub-Setup-0.2.0-x64.exe` below.
- **Requirements:** Windows 10 (1809+) or Windows 11 (64-bit).
