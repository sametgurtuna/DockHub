### What's New in v0.3.1

Interactive cards for Clock and Media Player widgets, task termination improvements, and magnifier animation optimization.

---

#### Interactive Widget Popups
- **Clock & World Clock Cards:** Clicking the Clock or World Clock opens an interactive card displaying digital time with ticking seconds, full date details, and active timezone information.
- **Media Player Popup:** Clicking the Media Player widget opens a popover with high-resolution album artwork, track and artist metadata, an interactive seek bar, playback controls, and a master volume slider.

---

#### Reliability & Optimization
- **Responsive Process Termination:** Resolved UI delays when clicking "End Task" on running applications by offloading termination logic to background tasks with Win32 EndTask and fallback mechanisms.
- **Context Menu Interaction:** Fixed an issue where clicking child submenu items would prematurely dismiss the context menu without registering the click.
- **Application Icon Fallbacks:** Enhanced icon extraction with direct window handle (`WM_GETICON`) queries, process ID resolution, and graceful fallbacks for custom or script-based apps.
- **Magnification Tuning:** Confined wave magnification strictly to application buttons, preventing layout overlap on widget tiles.

---

### Download & Installation
- Download and run `DockHub-Setup-0.3.1-x64.exe` to install or upgrade.
- **Requirements:** Windows 10 (1809+) or Windows 11 (64-bit).
