### What's New in v0.4.0

DWM live window thumbnails with Aero Peek, native shell jump lists, unread notification badges, drag-to-app interaction, and an extensive performance overhaul.

---

#### DWM Live Previews & Aero Peek
- **High-Performance Live Thumbnails:** Hovering over running applications displays live Desktop Window Manager (DWM) previews with window titles and quick close buttons.
- **Aspect Ratio & Edge Awareness:** Thumbnail cards dynamically compute aspect ratios, scale gracefully up to 8 windows per group, and adjust position near screen boundaries.
- **Cursor Corridor Tracking:** Smooth cursor transition between dock icons and preview cards with tolerance margins preventing premature dismissal.

---

#### Shell Jump Lists & Notification Badges
- **Native Jump Lists:** Right-click application buttons to access application-specific tasks (e.g. New Window, Private Browsing for Chrome/Edge/Firefox) and recent documents.
- **Unread Notification Badges:** Automatic detection of unread counts from window titles (Discord, Slack, Telegram, WhatsApp, Outlook) displayed as red badge pills on dock icons.
- **Drag-to-App & Hover-to-Focus:** Dragging files onto dock icons launches the app with arguments; hovering for 400 ms automatically brings the window to the foreground for dragging into canvases or chats.
- **Global Shortcut:** `Win + Alt + D` (or `Ctrl + Alt + D`) toggles dock visibility from anywhere.
- **Per-Monitor v2 DPI Scaling:** Handles dynamic display scaling changes without blurriness or layout lag.

---

#### Performance & Optimization Overhaul
- Replaced global window scans with targeted Win32 lookups, significantly decreasing idle background CPU usage.
- Offloaded network adapter enumeration and disk I/O to background tasks, eliminating micro-stutters.
- Fixed unmanaged Win32 GDI icon handles and COM audio session memory leaks.
- Optimized mouse wheel stepping for high-precision free-spinning mice and precision touchpads.
