### What's New in v0.6.0

Comprehensive multi-monitor capabilities, per-display window tracking, dynamic display hot-plugging, and refined dock sizing metrics.

---

#### Multi-Monitor Desktop Support
- **Dock on Every Display:** Enable *Settings › Appearance › Show on all displays* to place a functional dock across all connected monitors.
- **Primary vs. Secondary Docks:** The primary display retains widgets, system tray icons, and global hotkeys, while secondary docks present pinned items, running apps, Start, and the clock.
- **Display-Specific Running Apps:** Open windows can be set to appear exclusively on the dock of the monitor where their window resides, updating dynamically as windows are moved.
- **Dynamic Hot-Plugging:** Docks automatically initialize, scale, and clean up as external displays are connected or disconnected.
- **Context-Aware Start:** Start, Search, and Notification Center open aligned to the specific dock monitor where clicked.

---

#### Typography & Layout Refinements
- **Proportional Size Metrics:** Recalculated bar thickness across standard dimensions (Small: 50 DIP, Medium: 56 DIP, Large: 64 DIP) preventing widget label clipping.
- **Subpixel Text Rendering:** Switched to ideal font formatting for crisp, distortion-free text on scaled and high-DPI displays.
- **Reliable Drag-and-Drop Ordering:** Improved item reordering logic when dragging items across multi-monitor docks.

---
