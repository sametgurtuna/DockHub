### What's New in v0.6.1

A maintenance update completing per-display dock size customization across multi-monitor setups.

---

#### Per-Display Size Configuration
- **Independent Sizing:** Secondary displays can now be assigned independent dock sizes (Small, Medium, Large, or *Same as main dock*) under *Settings › Position*.
- **Consistent Scaling:** The primary dock maintains its global size preference while secondary monitors adapt to different viewing distances and screen dimensions.

---

### Download & Installation
- **Installer:** Download `DockHub-Setup-0.6.1-x64.exe` below. Existing installations can update in place without losing settings.
- **Requirements:** Windows 10 (1809+) or Windows 11 (64-bit).
