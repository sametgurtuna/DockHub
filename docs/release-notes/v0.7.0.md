### ✨ What's New in v0.7.0

The biggest DockHub update so far: fixes for the most reported problems, a proper keyboard story, a safety net for every change you make, and a much friendlier first run.

#### 🐞 Fixed: Missing Icons, Hidden Apps and Window Previews
- **Icons no longer disappear.** When Windows couldn't hand over an app's icon (typically right after sign-in or while an app was updating), the button stayed empty. DockHub now shows a placeholder and keeps retrying until the real icon loads. It also retries after sleep, display changes and Explorer restarts.
- **Pins survive app updates.** Apps like Discord, Slack and Microsoft Store apps (Claude, Windows Terminal...) install every update into a new versioned folder, which broke pins made by dragging a running app to the dock. Pins now point at a stable launcher, and existing broken pins are repaired automatically on start.
- **Discord and other tray apps show up again.** Apps that create their window hidden and show it later (Discord and other Electron apps, apps restored from the tray) now appear on the dock as soon as their window opens.
- **Middle-click closes windows in previews.** Hover an app, then middle-click a thumbnail to close that window, just like on the Windows taskbar. Closed windows drop out of the preview immediately, and previews open on the correct side for top, left and right docks.

#### ⌨️ Keyboard Shortcuts
- **Win + 1…9 / Win + 0** open, switch to or minimize the dock's first ten apps. Add **Shift** for a new window, **Ctrl + Shift** to run as administrator, **Alt** for the jump list. Hold **Win** to see the numbers on the dock.
- **Your own global shortcuts** for showing the dock, opening settings, pinning an app, toggling auto-hide, muting and changing the volume. Set them in **Settings > General > Keyboard shortcuts**; shortcuts another app already uses are flagged.
- **Show the dock** now defaults to `Ctrl + Alt + D` (`Win + Alt + D` is taken by Windows 11).

#### 🔊 Network, Volume and Battery Icons
- DockHub now draws its own **volume** and **battery** icons next to the network icon, because Windows 11 keeps its real ones inside Explorer. Scroll the volume icon to change the volume, middle-click to mute, right-click to switch the output device. The battery icon shows the charge and time left, and only appears on devices with a battery.
- Windows' classic duplicates of these icons are hidden automatically. Each icon can be turned off in **Settings > Taskbar**.

#### ↩️ Undo, Backups and Update Checks
- **Undo.** Removed a widget, deleted a folder or applied a layout by mistake? Click **Undo** on the toast next to the dock, use **Undo** in the dock's right-click menu, or press `Ctrl + Z` in Settings. Sticky notes and other widget data come back too.
- **Safer deletes.** Removing a folder that still has items asks whether to move them back to the dock or delete them. Switching the taskbar mode asks before restarting.
- **Backup and restore.** Export your whole setup (dock, widgets, notes, reminders) to a `.zip` and import it on another PC in **Settings > General**.
- **Automatic daily backups.** DockHub keeps a copy of its settings from each of the last 7 days and loads the newest one by itself if the settings file is ever damaged.
- **Update checks.** DockHub looks for a newer release once a day and can download (checksum-verified) and install it for you from **Settings > About**. Turn it off there if you prefer.

#### 🎨 A Friendlier First Run and Settings
- **Welcome tour** on first start: what happened to your taskbar, the taskbar mode, the screen edge and a starting layout.
- **Layout presets:** Minimal, macOS style, Dashboard and Side bar. Your apps and folders are always kept.
- **Search in Settings** (`Ctrl + F`) finds any setting or widget and highlights it.
- **Live preview** of the dock on the Appearance page while you change edge, size, shape and tint.
- **Widgets that collapse when idle.** Now playing, sticky notes and reminders shrink to a small tile when there's nothing to show and open in full on click. Switch it per widget with **Collapse when idle**.

### 🛠️ Improvements & Fixes
- **Add application** in a folder's menu now adds the app to that folder instead of the dock.
- Removed widgets' data (for example sticky notes) is kept for 7 days in `data\trash` so an undo can restore it.
- Widgets that a newer or older DockHub doesn't know are kept in your settings instead of being deleted.
- **AI usage:** choose how often it checks (5 to 60 minutes, default 15), **Refresh now** from its menu, clearer error states, red rings near a limit. Automatic checks pause if the Claude CLI's output isn't recognized, so it can't use your quota repeatedly.
- Scroll arrows now sit at both ends of the item area, and a dot on the arrow tells you when a newly opened app landed out of view.
- **Dock items** in Settings: filter box (folder contents included) and a hint when a pinned file no longer exists.
- **Copy diagnostics** (Settings > About) reports how DockHub sees your windows, tray icons and pinned apps, for bug reports.
- The Edge margin setting is disabled for attached docks, where it has no effect.
- New unit test suite and GitHub Actions builds for every change.
