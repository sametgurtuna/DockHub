### What's New in v0.7.0

A major release delivering icon stability fixes, 4 new widgets, Turkish localization, global keyboard shortcuts, backup/restore tools, and the Web Widget SDK.

---

#### Core Reliability & Icon Fixes
- **Robust Icon Recovery:** Placeholder fallbacks with automatic retry mechanisms ensure icons never stay blank after system startup, sleep recovery, or Explorer restarts.
- **Resilient Application Pins:** Application pins point to stable launcher paths, preventing broken pins when Electron and Microsoft Store applications update into versioned directories.
- **Background App Detection:** Window creation hooks immediately detect applications initialized in hidden or minimized states (Discord, Steam, Slack).
- **Preview Thumbnail Enhancements:** Middle-click window previews to close windows instantly, with proper popover orientation on all dock edges.

---

#### Keyboard Navigation & Global Hotkeys
- **Number Key Launchers:** Press `Win + 1` through `Win + 0` to launch, switch to, or minimize dock items. Hold `Win` to display visual number badges.
- **Custom Global Shortcuts:** Configurable system-wide shortcuts for dock toggle, settings, auto-hide, volume adjustment, and audio mute (*Settings › General › Keyboard shortcuts*).

---

#### New Widgets & Custom Web SDK
- **Calendar:** Displays upcoming meetings from any standard iCal (.ics) subscription (Google Calendar, Outlook) with one-click Zoom, Teams, and Google Meet integration.
- **Clipboard History:** Secure in-memory history of the last 25 copied texts and images with pinning support. Password manager entries are automatically ignored.
- **Folder Stack:** Quick-access stack for Downloads or custom folders with direct drag-and-drop out of the dock.
- **Exchange Rates:** Daily foreign exchange rates powered by the European Central Bank with historical trend indicators.
- **Web Widget SDK:** Build custom widgets using standard HTML, CSS, and JavaScript. Includes security sandboxing, local storage, and granular network permissions.

---

#### User Experience & Management
- **Turkish Interface (Türkçe):** Complete UI translation into Turkish.
- **Undo & Configuration History:** Full Undo support (`Ctrl + Z`), automatic daily backups (retained for 7 days), and complete configuration export/import.
- **Profiles & Smart Auto-Hide:** Multi-profile support with smart auto-hide that conceals the dock only when overlapped by an active window.
- **Accessibility:** Screen reader (Narrator) labels, high-contrast theme support, and reduced motion settings.
