### What's New in v0.8.0

Enhanced desktop integration with maximized window reservation, a Spotlight-style Quick Launcher, tray indicators, 5 new widgets, and automated profile switching.

---

#### Window Reservation & Quick Launcher
- **Reliable Workspace Reservation:** Maximized windows now respect the dock across all monitor DPI scales (100%, 125%, 150%+), with automated self-healing if another process clears work-area margins.
- **Spotlight-Style Quick Launcher:** Press `Win + Alt + Space` to summon a clean search palette above the dock. Search applications, open windows, settings, recent documents, and perform quick inline calculations.

---

#### System Indicators & Window Interactions
- **System Tray Indicators:** Added input language indicator (with quick-switch), active microphone status (with app usage tooltip and mute toggle), and notification badge counters with Focus/Do Not Disturb status.
- **Virtual Desktop Indicator:** Displays current desktop number with mouse-wheel desktop switching and multi-desktop window aggregation.
- **Interactive Previews:** Aero Peek hover support, mouse-wheel thumbnail cycling, and integrated media playback controls (Play/Pause) on supported apps.

---

#### New Productivity Widgets
- **GPU Monitor:** Real-time graphics processing load and VRAM utilization matching Task Manager metrics (available as percentages, rings, or sparkline bars).
- **Display Brightness:** Integrated DDC/CI monitor and laptop screen brightness slider with Night Light status.
- **Quick Toggles:** One-click Wi-Fi and Bluetooth toggles.
- **Screen Capture:** Instant region snipping or full-screen capture saved directly to *Pictures › Screenshots*.
- **To Do:** Local offline task management or bi-directional synchronization with Todoist.
- **AI Usage:** Expanded to monitor OpenAI Codex and Gemini CLI quotas alongside Claude Code.

---

#### Automated Profiles & Web Widgets
- **Rule-Based Profiles:** Automatically activate dedicated dock profiles based on running processes (e.g. gaming) or scheduled time windows.
- **URL-Based Web Widget Installation:** Install widgets directly from GitHub links or manifest URLs with upfront security permission verification.
- **Visual Customization:** Theme file export/import (`.dockhub-theme`), custom layout presets, and uniform widget grid alignment.

---

### Download & Installation
- **Installer:** Download `DockHub-Setup-0.8.0-x64.exe` below. Existing installations can also update directly from *Settings › About*.
- **Requirements:** Windows 10 (1809+) or Windows 11 (64-bit).
