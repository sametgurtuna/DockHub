### ✨ What's New in v0.8.0

DockHub now behaves even more like a real taskbar: maximized windows stop at the dock, the tray shows your keyboard language, microphone and notifications, and a Spotlight-style launcher is one shortcut away. Five new widgets, AI usage for Codex and Gemini, profiles that switch by themselves, and web widgets you can install from a link.

#### 🐞 Fixed: Maximized Windows Slid Under the Dock
- **Maximized apps now stop at the dock**, exactly like the Windows taskbar. The dock reserves its band of the screen at every display scaling (100 %, 125 %, 150 %...) and on every display that has a dock.
- DockHub checks the reservation after display, scaling and Explorer changes and repairs it by itself if Windows or another app resets it.

#### 🔎 Quick Launcher
- **Win + Alt + Space** (or the search button, if you choose so in **Settings > Taskbar > Search button opens**) opens a Spotlight-style search box above the dock.
- Finds **apps**, **open windows**, **DockHub settings**, **Windows settings pages**, **recent files** and **dock commands** (auto-hide, mute, lock, new virtual desktop, switch profile...). Initials work too: `vsc` finds Visual Studio Code.
- **Quick math** (`200*15%`, `(4+2)^2`, `sqrt(2)`, decimal comma or point); Enter copies the result. Anything else can be searched on the web.

#### 🧭 Taskbar Indicators
- **Input language:** with more than one keyboard language, a short code (TUR, ENG...) sits next to the tray. Click or scroll it to switch, right-click for the full list.
- **Microphone:** an icon appears while an app records, like on Windows, or always if you prefer. Click to mute or unmute (there's a shortcut for it too); the tooltip lists the apps using the microphone.
- **Notifications and Do Not Disturb:** the clock shows how many notifications wait in the notification center, and a moon while Do Not Disturb or Focus is on.
- **Virtual desktops:** a number next to Task View shows which desktop you're on. Scroll it to switch desktops, right-click to add or close one. **Apps from all desktops** lists windows of every desktop on the dock.

#### 🪟 Livelier App Buttons and Previews
- **Launch feedback:** an app's icon bounces while it starts, until its first window appears.
- **Peek at windows:** rest the pointer on a preview thumbnail to see that window on its own (Aero Peek style).
- **Scroll to cycle** through an app's windows in the preview.
- **Play / pause** right in the preview of apps that are playing media (Spotify, browsers and more).

#### 🧩 New Widgets
- **GPU:** graphics card load and video memory, from the same counters Task Manager uses. Numbers, rings or bars.
- **Brightness:** scroll to change the brightness of laptop screens and DDC/CI monitors, with a slider in its panel; shows when night light is on.
- **Wi-Fi and Bluetooth:** switch them on or off in one click, like Quick Settings.
- **Screenshot:** one click opens the Windows snipping overlay; the other button saves every screen to *Pictures › Screenshots* and copies it. Optional countdown.
- **To do:** today's tasks, either a simple list kept on this PC or today's and overdue tasks from **Todoist** (your personal API token is stored encrypted). Tick to complete, type to add.

#### 🤖 AI Usage for Codex and Gemini
- The **AI usage** widget now also tracks **OpenAI Codex** (5-hour and weekly limits) and **Gemini CLI** (requests today against your daily limit). Pick the assistant in the widget's settings. Codex and Gemini are read from the logs those tools keep on your PC: no extra process, no sign-in.

#### 🗂️ Profiles That Switch by Themselves
- A profile can now switch in **while an app runs** (for example `steam` or `cs2`) or **during set hours** (weekdays only if you like), next to the existing display-count rule. When the app closes or the hours end, DockHub goes back to the profile you had. Set rules in **Settings > Profiles**.

#### 🌐 Web Widgets From a Link
- **Install from link:** paste a link to a `manifest.json`, a `.dockwidget` file or a GitHub folder in **Settings > Widget gallery**. You see the widget's permissions before anything is installed.
- **Featured web widgets** install with one click, including a new **GitHub pull requests** widget: reviews waiting for you, your open pull requests or unread notifications, with a notification when something new arrives.
- Widget authors can list extra files in the manifest's new `files` field. See `docs/widget-sdk.md`.

#### 🎨 Settings and Appearance
- **Tidier settings:** Profiles, Keyboard shortcuts and **Backup and troubleshooting** now have their own pages, so General is short again.
- **Text size** for settings, widget panels and menus (System follows Windows' text size).
- **Even widget widths:** widget cards round their width up to a common grid, so the dock keeps an even rhythm.
- **Theme files:** export your dock's look (colors, glass, size, shape and position) to a `.dockhub-theme` file and share it; import one with a click.
- **Save current layout as a preset:** keep your look and widgets as your own preset and apply it again later.

#### 🇹🇷 Türkçe
- Every new screen is translated, and texts that still appeared in English in the Turkish interface (widget tooltips, notifications, settings rows) are now Turkish too.

---

### 🛠️ Improvements & Fixes
- The dock's reserved area is restored cleanly when DockHub exits or moves to another edge or display.
- Screenshot notifications have **Open** and **Show in folder** buttons.
- Web widget install errors are clearer and translated; links must use HTTPS and files must stay next to the manifest.
- **winget:** a release workflow submits each new version to the Windows Package Manager (`winget install SametGurtuna.DockHub` once the package is accepted).
- More unit tests (125 in total) for the launcher math, profile rules, Codex and Gemini log parsing and link installs.

### 📥 Download & Install
- **Installer:** Download `DockHub-Setup-0.8.0-x64.exe` from Assets below and run it. It upgrades your existing install in place and keeps your settings. If you have 0.7.0, you can also install it from **Settings > About**.
- **Requirements:** Windows 10 1809 or newer / Windows 11, x64.
