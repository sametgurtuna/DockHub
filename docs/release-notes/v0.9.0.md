### ✨ What's New in v0.9.0

The Device batteries widget now reads far more devices and warns you before one runs flat. Widgets can live on the dock of any display, the interface speaks German and Spanish, and web widgets get a community list, one-click `.dockwidget` files and access to servers on your own network. Under the hood, DockHub starts faster and does less while it waits.

#### 🔋 Many More Devices in Device Batteries
- **Xbox controllers**, and any other controller that reports its battery to Windows, over the Xbox Wireless Adapter, Bluetooth or a cable.
- **PlayStation:** DualShock 4, DualSense and DualSense Edge, with their charging state.
- **Logitech** mice and keyboards on Unifying, Lightspeed and Bolt receivers, on a cable or over Bluetooth (HID++ 2.0 devices).
- **Razer** wireless mice (Viper, DeathAdder, Basilisk, Naga and Orochi models), on the receiver or the cable.
- **SteelSeries Arctis 7**, next to the HyperX headsets and the LAMZU Atlantis Mini that were already supported.
- **Bluetooth fixed:** the Bluetooth scan used a wrong identifier and could miss every device. It now finds classic and Low Energy devices, and reads the standard battery service of Low Energy devices that Windows shows no level for.
- **Your own devices:** a model with a supported protocol but an unknown product id can be added in `%AppData%\DockHub\battery-devices.json`. See `docs/battery-devices.md` for the list and the format.
- Keyboards and controllers have their own icons. DockHub only ever asks for the battery level; it never changes a device's settings.

#### 🪫 Low Battery Warning
- A notification when a device drops to **15 %** (choose 5 to 30 %, or Off, in the widget's settings under **Low battery warning**).
- One warning per device. It warns again only after the device has been charged, not every time it wakes up.

#### 🖥️ Widgets on Every Display
- With **Show on all displays**, each widget can now sit on the dock of **any display**, not only the main one. Right-click a widget › **Show on**, drag it to another dock, or pick the display in **Settings > Dock items**.
- A widget lives on one dock at a time. When its display is disconnected it moves to the main dock, and it goes back when the display returns.

#### 🌍 Deutsch und Español
- The whole interface is now available in **German** and **Spanish**, next to English and Turkish. Choose it in **Settings > General > Language**; *System* follows your Windows display language.
- The installer speaks both languages too.

#### 🪙 Crypto Prices
- The **Exchange rates** widget now shows **crypto prices** from CoinGecko: Bitcoin, Ethereum, Solana and 16 more, in your base currency, with the change since yesterday and a two-week trend. Mix them freely with currencies, for example `EUR, BTC, ETH`.

#### 🌐 Web Widgets
- **Community list:** the widget gallery shows web widgets from DockHub's community list on GitHub, updated daily. Anyone can add a widget to it with a pull request (`samples/widgets/index.json`).
- **Double-click a `.dockwidget` file** to install it, even while DockHub is running. Packages are checked for size and for files outside their folder before anything is unpacked.
- **Two new samples:** **GitHub Actions** (the latest workflow run of a repository, with a notification when it fails) and **Home Assistant** (the state of an entity; click to switch lights and plugs).
- **For widget authors (SDK apiVersion 2):** `networkFromSettings` lets a widget reach the server address the user enters in its settings, over https or plain `http` (for servers on your network), and `dockhub.http.request` makes requests to the allowed hosts. With `"debugLogging": true`, widgets reload as soon as you save a file. See `docs/widget-sdk.md`.
- Web widgets now light up on hover like the other widgets.

#### 🐞 Report a Problem
- **Settings > About > Report a problem** opens a GitHub bug report with your DockHub and Windows versions, language, display count and widgets already filled in. Nothing personal goes into the link. It also copies the diagnostics report, which you can paste in if it helps.

### 🛠️ Improvements & Fixes
- **Faster start:** DockHub draws the dock first and creates each service only when a widget needs it. The first battery, weather and AI usage requests follow a few seconds later instead of all at once. `log.txt` records the time to the first dock frame.
- The device battery scan only runs while a Device batteries widget is on the dock, and only opens the USB devices it knows.
- Widget cards use three standard widths, so the dock keeps an even rhythm with **Even widget widths** on.
- A refresh requested while a battery scan is running is no longer lost.
- Release builds can be code signed, and the winget submission is documented step by step (`packaging/`).
- About 350 unit tests (up from 125), including every battery protocol, all four languages and the new web widget checks.

### 📥 Download & Install
- **Installer:** Download `DockHub-Setup-0.9.0-x64.exe` from Assets below and run it. It upgrades your existing install in place and keeps your settings. If you have 0.8.x, you can also install it from **Settings > About**.
- **Requirements:** Windows 10 1809 or newer / Windows 11, x64.
