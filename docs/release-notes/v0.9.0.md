### What's New in v0.9.0

Expanded hardware battery monitoring, multi-display widget placement, German and Spanish localization, cryptocurrency market rates, and enhanced Web Widget capabilities.

---

#### Expanded Device Battery Support
- **Broad Controller Support:** Xbox wireless controllers (via Xbox Wireless Adapter, Bluetooth, or USB cable) and PlayStation controllers (DualShock 4, DualSense, DualSense Edge) with charging indicators.
- **Peripherals:** Logitech mice and keyboards across Unifying, Lightspeed, and Bolt receivers (HID++ 2.0 protocol), Razer wireless mice, and SteelSeries Arctis 7 headsets.
- **Bluetooth Low Energy:** Improved BLE battery service discovery for devices not exposed in standard Windows settings.
- **Low Battery Warnings:** Configurable low-battery notifications (triggering between 5% and 30%) with smart deduplication.

---

#### Multi-Display & Interface Localization
- **Widgets on Any Display:** When *Show on all displays* is enabled, widgets can be assigned to secondary monitors via right-click or drag-and-drop.
- **German & Spanish Localization:** Complete translation of the entire interface and installer into German (Deutsch) and Spanish (Español), alongside English and Turkish.
- **Crypto & Forex Rates:** Real-time crypto asset tracking (BTC, ETH, SOL, and 16+ tokens via CoinGecko) integrated alongside ECB foreign exchange rates.

---

#### Web Widgets SDK 2.0
- **Community Directory:** Discover and install curated web widgets directly from the GitHub community index in Settings.
- **Direct Package Installation:** Double-click `.dockwidget` archives to inspect permissions and install immediately.
- **Local Network Access:** Added `networkFromSettings` and `dockhub.http.request` to communicate with local home automation and IoT servers (e.g. Home Assistant).
- **Developer Live Reload:** Automated reload on file save when `"debugLogging": true` is enabled in settings.

---

#### Performance & Diagnostic Tools
- Staggered background service initialization, speeding up time-to-first-frame on system boot.
- One-click diagnostic export and pre-filled GitHub issue template under *Settings › About › Report a problem*.

---

### Download & Installation
- **Installer:** Download `DockHub-Setup-0.9.0-x64.exe` below. Existing installations can also update directly from *Settings › About*.
- **Requirements:** Windows 10 (1809+) or Windows 11 (64-bit).
