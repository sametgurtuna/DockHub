### ✨ What's New in v0.9.1

A patch for the problems you reported after 0.9.0: the dock's position no longer resets when you change its design, the weather widget keeps its city, the network and volume icons next to the tray work reliably, and DockHub does less while it waits.

#### 📍 Position and Design Are Separate
- **Applying a layout preset no longer moves the dock.** Put the dock on the right, pick *Minimal*, *macOS style* or *Dashboard*, and it stays on the right. Before, every preset sent the dock back to the bottom.
- *Side bar* keeps a dock that is already on the left or right where it is, and only moves a top or bottom dock to the left.
- Your own saved layouts and imported `.dockhub-theme` files don't change the position either. Themes now carry colors, glass, size and shape only; the position in older theme files is ignored.

#### 🌤️ Weather Keeps Its City
- Switching to a preset without the weather widget and back no longer resets it to the default city. DockHub remembers the settings of widgets a preset takes off (city, units and the rest) and gives them back when a later preset brings the widget back.

#### 🔊 Network and Volume Icons
- **Clicking the network, volume or battery icon opens Windows' quick settings every time.** Windows positions that panel next to the taskbar DockHub tells it about. The Start button and the clock updated that position first, but these icons didn't, so the panel sometimes didn't open or opened in the wrong place until you had clicked the clock.
- **Volume no longer stops responding after you switch output devices.** Plugging in headphones or connecting a Bluetooth speaker sends several notifications at once. DockHub rebuilt its volume connection from two of them at the same time and could lose it; the icon and the audio widget then ignored the wheel and showed a stale level until DockHub restarted. The changes are now handled one at a time.
- **The network icon shows the connection you actually use.** It reads Windows' own connection list, like the taskbar, so Hyper-V, WSL, VPN and VirtualBox adapters no longer show a cable while you're on Wi-Fi. When you're connected but the network doesn't reach the internet, the icon dims and its tooltip says so.

#### ⚡ Lighter on Resources
- DockHub no longer asks Windows five times a second whether Start or Search is open. Windows now tells it when that changes, with a slower check kept as a safety net (it speeds back up by itself on systems where those notifications don't arrive).
- Leaner memory settings for the .NET runtime: no background garbage-collection thread, eager heap compaction and no profile-guided tiering, which only pays off for busy server code.
- On the same PC and settings, measured over a minute of idle time after startup: average CPU went from **0.28 % to 0.09 %**. Memory stays about the same (66 MB private working set, 69 MB before).

### 🛠️ Improvements & Fixes
- The layout preset descriptions and the theme export text say what they now keep and share, in all four languages.
- 8 new unit tests for presets, saved layouts, theme files and the weather settings (358 in total).

### 📥 Download & Install
- **Installer:** Download `DockHub-Setup-0.9.1-x64.exe` from Assets below and run it. It upgrades your existing install in place and keeps your settings. If you have 0.9.0, you can also install it from **Settings > About**.
- **Requirements:** Windows 10 1809 or newer / Windows 11, x64.
