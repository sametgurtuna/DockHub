### What's New in v0.9.1

A focused update improving dock position persistence across design changes, weather settings retention, and network/audio tray responsiveness.

---

#### Position & Design Separation
- **Independent Layout Presets:** Applying a preset (Minimal, macOS style, Dashboard) no longer resets the dock to the bottom screen edge. Your chosen dock position is preserved.
- **Theme File Compatibility:** Exported `.dockhub-theme` files now manage colors, glass effects, size, and shape without overriding the user's screen position.

---

#### Weather & Taskbar Improvements
- **Persistent Widget Settings:** Switching between layout presets preserves custom widget configurations (such as Weather cities and units) even when temporarily removed from the dock.
- **Reliable Quick Settings Access:** Clicking the network, volume, or battery icons consistently aligns and triggers the Windows Quick Settings flyout.
- **Multi-Device Volume Synchronization:** Resolved an audio endpoint race condition where switching between headphones and Bluetooth speakers could cause volume controls to become unresponsive.
- **Accurate Network Adapter Detection:** The network indicator now mirrors the active default route, preventing virtual adapters (WSL, Hyper-V, VPN) from displaying false wired connection states.

---

#### Performance & Optimization
- Replaced tight timer loops for Start and Search detection with responsive Windows event notifications, reducing idle CPU usage from ~0.28% to ~0.09%.
- Tuned runtime memory allocations for lower background footprint.

---
