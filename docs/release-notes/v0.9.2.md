### ✨ What's New in v0.9.2

A hotfix for 0.9.1: the dock could close on its own, icons looked soft on very sharp displays, and a "transparent" dock could turn black.

#### 💥 Fixes the Random Closing
- **The dock no longer disappears by itself.** After 0.9.1, DockHub could end without any message a few times a day on some PCs (Windows logged a crash inside the .NET runtime while the dock was talking to Windows). 0.9.0 never did this, so 0.9.2 goes back to how 0.9.0 handled two things 0.9.1 had changed only to save a little CPU:
  - Start/Search visibility is checked with a short poll again instead of a Windows event subscription.
  - The .NET memory settings are back to the defaults (background garbage collection, no eager heap compaction).
- The trade-off is about 0.2 % more CPU while the PC is idle. Everything else 0.9.1 fixed stays: the dock keeps its position across presets, weather keeps its city, the volume, network and battery icons open quick settings reliably.
- If DockHub still closes by itself, please tell us: *Settings › About › Report a problem* collects the log.

#### 🖼️ Sharper Icons on High-DPI Displays
- App icons were always loaded at 96 px. On displays scaled 250 % or more, and with the large dock size or the hover zoom, that was stretched. DockHub now asks Windows for 128, 192 or 256 px depending on your sharpest display (nothing changes at 100 %–225 %).

#### 🪟 Transparent Background
- **New *Transparent* option in *Settings › Appearance › Backdrop*.** It shows the desktop behind the dock through your tint, with no blur. Blur and Acrylic rely on a Windows effect that some graphics drivers (seen on laptops with two GPUs) draw as solid black; Transparent does not depend on it, so it shows the real color behind the dock everywhere. Try it if your dock looks black.
- Very old (version 1) config files that stored `Transparent` still open as a solid dock; from now on the name means the new option.
